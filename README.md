# Beethoven Fluid Remix

贝多芬第五交响曲《命运》的电子混音 + 跟着节拍跳舞的 GPU 流体模拟。零依赖、零采样、零构建工具——所有声音和画面都是代码实时生成的。

## 运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

点击播放按钮(或按空格)。拖动画面可以搅动流体。

## 它是怎么工作的

### 音乐 — `audio.js`

全部声音由 Web Audio API 实时合成,没有任何音频文件:

- **音序器**:126 BPM,32 小节循环,结构为 命运动机 → DROP A → BREAK(琶音+riser)→ DROP B → CODA,用 lookahead 调度保证采样级精确时序
- **主奏**:双锯齿波失谐 + 方波低八度,低通包络,附点八分延迟回声,演奏"当当当——当"动机及其变奏
- **鼓机**:Kick(正弦扫频 150→38 Hz)、Snare(带通噪声+三角波)、Hi-hat(高通噪声)、Crash、噪声 riser
- **贝斯**:锯齿+正弦次低音,反拍泵感

### 流体 — `fluid.js`

WebGL2 上的 stable-fluids 求解器(半拉格朗日平流 + 涡量约束 + Jacobi 压力投影),速度场 144p / 染料场 720p,半浮点纹理。

### 节拍编舞 — `main.js`

音序器在调度每个音符时同时生成可视化事件队列,渲染循环按 AudioContext 时钟精确消费:

| 音乐事件 | 流体反应 |
| --- | --- |
| Kick | 底部中央冲击波环 |
| Snare | 两侧向内的钳形射流 |
| 主旋律音符 | 按音高定位的彗星溅射(音高→横坐标,音高→色相) |
| 贝斯 | 沿地面的暗红慢速绽放 |
| 琶音 | 旋转轨道溅射 |
| Riser | 全场向上螺旋 |
| Crash | 中心超新星爆发 |

### 上传你自己的歌

点击 ♫ 按钮或直接把音频文件拖进页面,歌曲会在本地解码播放(不上传到任何服务器)。

为了兼容各种音乐风格(安静的民谣 vs 重压缩的 EDM),分析管线做了三层自适应归一化:

1. **整体响度归一化(AGC)**:解码后扫描全曲 RMS,用增益节点拉到统一响度目标,后接限幅器防削波——不同歌的整体音量差异在进入分析器之前就被抹平
2. **逐频段滚动归一化**:每个频段在线跟踪自己的 p10/p90 能量包络,能量映射到 0~1 后再驱动涡量/辉光——频谱形状差异(贝斯重 vs 人声为主)也被消化掉
3. **z-score 触发 + 事件率反馈闭环**:onset 用 (e−μ)/σ 衡量「意外程度」而非绝对响度;触发阈值本身由反馈控制,实际事件率高于目标(鼓点 ~2/s、军鼓 ~2.5/s、旋律 ~3/s)就抬高阈值,低于就放低——无论什么风格,画面密度都收敛到同一个视觉节奏区间。另有不应期和噪声门防止安静段落误触发

事件映射:低频 onset→Kick 冲击波,高频 onset→Snare 射流,中频 onset→按 150 Hz–2.5 kHz 主导频率定位的旋律溅射,色相随播放缓慢漂移。

同时用 AnalyserNode 做连续驱动:低频能量 → 涡量强度(bass 越重涡旋越狂),高频 → 染料消散速度,整体能量 → 显示着色器的辉光。每个段落切换配色(动机=青铜金,DROP A=绯红,BREAK=青蓝,DROP B=紫红,CODA=金)。
