# Beethoven Fluid Remix

贝多芬第五交响曲《命运》的电子混音 + 跟着节拍跳舞的 GPU 流体模拟。零依赖、零采样、零构建工具——所有声音和画面都是代码实时生成的。

## 运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

点击播放按钮(或按空格)。拖动画面可以搅动流体。

## 它是怎么工作的

### 音乐 — `audio.js`

全部声音由 Web Audio API 实时合成,没有任何音频文件:

- **音序器**:126 BPM,32 小节循环,结构为 命运动机 → DROP A → BREAK(琶音+riser)→ DROP B → CODA,用 lookahead 调度保证采样级精确时序
- **主奏**:双锯齿波失谐 + 方波低八度,低通包络,附点八分延迟回声,演奏"当当当——当"动机及其变奏
- **鼓机**:Kick(正弦扫频 150→38 Hz)、Snare(带通噪声+三角波)、Hi-hat(高通噪声)、Crash、噪声 riser
- **贝斯**:锯齿+正弦次低音,反拍泵感

### 流体 — `fluid.js`

WebGL2 上的 stable-fluids 求解器(半拉格朗日平流 + 涡量约束 + Jacobi 压力投影),速度场 144p / 染料场 720p,半浮点纹理。

### 节拍编舞 — `main.js`

音序器在调度每个音符时同时生成可视化事件队列,渲染循环按 AudioContext 时钟精确消费:

| 音乐事件 | 流体反应 |
| --- | --- |
| Kick | 底部中央冲击波环 |
| Snare | 两侧向内的钳形射流 |
| 主旋律音符 | 按音高定位的彗星溅射(音高→横坐标,音高→色相) |
| 贝斯 | 沿地面的暗红慢速绽放 |
| 琶音 | 旋转轨道溅射 |
| Riser | 全场向上螺旋 |
| Crash | 中心超新星爆发 |

### 上传你自己的歌

点击 ♫ 按钮或直接把音频文件拖进页面,歌曲会在本地解码播放(不上传到任何服务器)。`TrackPlayer` 对实时频谱做 onset 检测:低频突变→Kick 冲击波,高频突变→Snare 射流,中频突变→按主导频率定位的旋律溅射,色相随播放缓慢漂移。

同时用 AnalyserNode 做连续驱动:低频能量 → 涡量强度(bass 越重涡旋越狂),高频 → 染料消散速度,整体能量 → 显示着色器的辉光。每个段落切换配色(动机=青铜金,DROP A=绯红,BREAK=青蓝,DROP B=紫红,CODA=金)。
